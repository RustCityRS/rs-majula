When do I report a bug?

When you spot something in Runescape that is not working as it should be. This could be anything from being unable to complete a quest to graphical glitches and typos. If you are sure that you have found a bug and it is easy to replicate you should report it via the Customer support Bug reporting system. If you can gain an unfair advantage by replicating the bug, please do not abuse it. Bug abuse is against the rules and players caught abusing bugs will be banned. You can find a detailed explanation of bug abuse under the Rules and Security section on the Runescape website.

How can I report a bug?

You can report a bug by going to the Customer support section of the Runescape website and clicking on Bug reporting. When filling out the bug report form please make sure you put as much detail as possible. This will help us find the bug and fix it asap. After the form has been filled out it will be sent to a member of Jagex staff to investigate. Please note that Jagex do not give rewards to players that report bugs.

Is there any reason not to send in a bug report?

Do not send in bug reports if you are simply stuck on part of a quest. Try all available options before submitting a bug report. Talk to all non player characters to see if there are any clues that have been overlooked. In some cases npc's will check to see if you already have an item before replacing it, make sure you check your bank and your inventory. Only submit a bug report if you are sure you have tried all other options. Players are reminded that we never replace lost or stolen items.

Where can I see bugs that have already been reported?

By going to the bug reporting system in the Customer support section of the RuneScape website you will see a list of bugs that have already been confirmed. You will be able to see if the confirmed bugs are waiting to be fixed, fixed awaiting to be uploaded, or already fixed. Please note that if we feel that a bug will encourage bug abuse it will not be posted on this list. Please do not report bugs that are already on the confirmed bug list.
